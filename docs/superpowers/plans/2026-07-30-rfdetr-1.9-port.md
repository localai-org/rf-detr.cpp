**Goal:** Port the code and converter half of `adithyab94/rf-detr.cpp` so rf-detr.cpp
runs RF-DETR 1.9 correctly, fixing a segmentation-head bug that has been dropping
blocks on four variants.

**Architecture:** Three independent changes to an existing C++/ggml inference engine.
(A) The segmentation head builds one `DepthwiseConvBlock` per decoder layer instead of
a hardcoded 4, guarded by a loader check that rejects pre-fix GGUFs with an actionable
error. (B) A new GGUF metadata key selects RF-DETR 1.9's antialias-free bilinear
preprocessing, defaulting to the legacy path when the key is absent. (C) The converter
uses `rfdetr`'s restricted checkpoint loader.

**Tech Stack:** C++17, ggml/GGUF, CMake + ctest, Python 3 converter (`torch` 2.5.1,
`rfdetr` 1.9.0, `gguf` 0.10.0).
